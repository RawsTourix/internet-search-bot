# Модули дизайн-документа

Основной документ проекта:

- [`../design_document.md`](../design_document.md) — архитектура ИИ-агента и общая дорожная карта `v0.3 → v0.8`.

Крупные самостоятельные модули, которые являются authoritative extensions
основного дизайн-документа:

1. [`v0.4-file-artifacts-advanced.md`](v0.4-file-artifacts-advanced.md) —
   **Часть VIII-F1. `v0.4-file-artifacts-advanced`**; логически располагается
   после `Часть VIII-F. v0.4-file-artifacts` и перед
   `Часть VIII-F2. v0.4-input-runtime`.

Правила модульной структуры:

- модуль не заменяет основной дизайн-документ, а расширяет указанную часть;
- при конфликте более новый явно помеченный authoritative module уточняет
  соответствующий старый раздел;
- module boundaries должны сохранять общую нумерацию частей и границы версий;
- implementation specification и code changes должны ссылаться на основной
  документ и соответствующий модуль;
- большие будущие дополнения допускается выносить в отдельные модули, если это
  снижает риск несогласованных точечных вставок в основной файл.
